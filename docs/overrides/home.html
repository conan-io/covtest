AI-native test selection

Run only the tests
that matter.

covtest maps every test to every line it covers.
When you change code, it selects the exact tests affected —
in seconds, not minutes.

Get started How it works
terminal
$ pytest -p covtest.predict
covtest: predicting tests
load snapshot : 2.9s
compute diff : 0.2s (1 file, 3 lines changed)
select tests : 0.1s (2 tests selected)

⚡

Seconds, not minutes

Select 2 tests from 5 000 in under 4 seconds. CI queues shrink. Developer feedback loops close. The bottleneck moves back to where it belongs — your code.

🤖

Built for agentic loops

AI coding agents make dozens of small changes per session. Without fast test selection, the test suite becomes the bottleneck that stalls every iteration. covtest gives agents instant signal.

🎯

No false negatives

Prediction is line-level, derived from real coverage data. If a test never executed a changed line, it is not selected — ever. Safety comes from data, not heuristics.

See it in action

01 Build the snapshot

Run your full suite once with coverage contexts. covtest process reads the data and stores a compact snapshot tied to the current commit.

02 Predict on every change

Edit a file, run covtest predict (or pytest -p covtest.predict). Only the tests that cover the changed lines are selected — in seconds.
